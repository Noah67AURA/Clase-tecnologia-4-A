# Mi idea
Para este trabajo, yo había pensado en crear una papelera la cual al tu echarle basura, ella misma, pueda detectar de que material es la basura que estás echando y dependiendo de lo que sea que lo lleve a su respectivo apartado de reciclaje.
Para que la papelera pueda detectar ella sola cuando se ha echado algo y el materia de lo que está hecho la basura, se puede usar:
| Componentes | Función |
|------------|----------|
|Sensor de movimiento| Para saber cuando se ha echado algo|
|Sensor inductivo| Para detectar el metal|
|Sensor infrarrojo| Para detectar el plástico, papel y vidrio|
|Cámara con IA| Para detectar los demás tipos de restos y no confundirlos|


Después de detectar el material, la papelera procederá a inclinar la base donde esta el residuo hacia el apartado correspondiemte.
Todo esto controlado por una placa arduino

# Idea grupal
En nuestro grupo, formado por Guillermo, Marco, Lorenzo y yo, hemos decidido escoger la idea de lorenzo, que trata de:

## Idea principal
Entre todos hemos elegido la idea de Lorenzo la cual es crear una caseta de pájaro inteligente, la cual tenga dispensadores de agua y comida para estos y en la que se detecte la humedad y temperatura del lugar. También se detectará cuando entre y salga un pájaro de la caseta, permitiéndonos saber en todo momento cuando hay actividad en la caseta. En nuestro caso no tenemos presupuesto suficiente presupuesto pero si se consigue desarrollar se podría poner una cámara la cual se encienda cuando se detecte que ha entrado un pájaro y con una IA que vaya conectada a la cámara que pueda reconocer el tipo de pájaro, toda esta información se podría comunicar al dueño del pájaro mediante una aplicación que esté conectada a la caseta, la cual aparte de enviarte el video con el tipo te dice directamente todos los datos como la humedad, comida, etc. 

## Lista de materiales, componentes y dispositivos de diseño
| Lista de materiales/Componentes/Dispositivos de diseño | Función |
|------------|----------|
| Sensor de movimiento (x1) | Detectar si entra un pájaro. Esta información sirve para saber si es necesario realizar cambios, como cambiar la ubicación de la caseta. |
| Sensor de temperatura y humedad (x1) | Detectar si existe un ambiente adecuado para los pájaros. |
| Sensor de ultrasonidos (x1) | Detectar si hay pájaros en los alrededores de la caseta. |
| Sensor de presión (x1) | Saber si hay algún pájaro posado en la entrada de la caseta. |
| Dispensador de agua | Mantener agua accesible para los pájaros. |
| Servomotor (x1) | Abrir la compuerta del sistema de agua para rellenar el dispensador. |
| Placa ESP32 Plus | Controlar todos los mecanismos y sensores del sistema. |
| Dispensador de comida | Almacenar la comida y permitir que los pájaros se alimenten directamente. |
| Sensor de nivel de agua (x2) | Detectar cuándo es necesario rellenar el depósito de agua. |
| Bomba de agua + tubo (x1) | Transportar el agua desde un depósito externo hasta la caseta. |
| Depósito de agua | Almacenar agua fuera de la caseta para evitar molestias a los pájaros al rellenarlo. |
| Cables | Realizar las conexiones eléctricas de la placa y los componentes. |
| Impresora 3D + filamento | Fabricar las piezas personalizadas de la caseta. |
| Cortadora láser | Dar forma y cortar piezas necesarias para la construcción de la caseta. |
